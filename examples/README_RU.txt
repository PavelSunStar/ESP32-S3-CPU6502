InstrTestV5_All16 -- автоматический запуск 16 тестов 6502 на ESP32-S3
====================================================================

1. Установите нашу библиотеку ESP32-S3-CPU6502 в Arduino IDE:
   https://github.com/PavelSunStar/ESP32-S3-CPU6502
2. ВАЖНО: для этого набора нужна рабочая CLI:
   uint8_t CPU6502::Instr_CLI() { _reg.SR.I = 0; return 0; }
   В таблице 0x58 должно стоять: {"CLI", &CPU6502::Instr_CLI, &CPU6502::IMP, 1, 2}
   Не перезаписывайте вашу последнюю исправленную версию библиотеки старой копией из GitHub.
3. Распакуйте ZIP с сохранением структуры каталогов.
4. Откройте InstrTestV5_All16/InstrTestV5_All16.ino в Arduino IDE.
5. Выберите ESP32-S3, загрузите скетч, откройте Serial Monitor (115200 бод).
6. Тесты запустятся автоматически по очереди. Ждите раздела FINAL SUMMARY.

ВЫВОД:
PASS     ROM записал успешный статус $6000=0.
FAIL     ROM сам сообщил об ошибке, код $6000=01..7F.
STOP     CPU остановился на опкоде, не обязательно означает ошибку теста.
TIMEOUT  Не завершён за 120 секунд (или 100 млн тактов).
RESET NEEDED  ROM просит более 3 мягких сбросов.

Отдельные ROM-тесты могут использовать неофициальные инструкции 6502,
которые наш учебный CPU пока не поддерживает. 15-brk может остановиться,
поскольку BRK в текущей версии CPU не реализован.
ROMы используют NROM/mapper0, без MMC1, CHR для CPU-тестирования не нужен.
Данные ROM загружаются во flash, а не занимают ~640 КБ оперативной памяти.
Для каждого теста память $0000-$7FFF очищается, PRG загружается заново.

ТЕСТЫ:
01-basics, 02-implied, 03-immediate, 04-zero_page,
05-zp_xy, 06-absolute, 07-abs_xy, 08-ind_x,
09-ind_y, 10-branches, 11-stack, 12-jmp_jsr,
13-rts, 14-rti, 15-brk, 16-special.

Источники: NESdev Emulator tests, blargg instr_test-v5 (Shay Green).
https://www.nesdev.org/wiki/Emulator_tests

Тестовый скетч подготовлен для устройства, но не был запущен на реальном
ESP32-S3. Результаты появятся только после прошивки.
